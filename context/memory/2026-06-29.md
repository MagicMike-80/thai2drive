**Goal**: Categories screen — 3D carousel to match webapp.py (per-category neon colors, drag, active ring, dots, edge fades)

**Deliverables**: `frontend/app/categories.tsx` — full rewrite from 2-column grid → 3D cylinder carousel

**Affected files**: `frontend/app/categories.tsx` (rewritten), `frontend/src/services/api.ts` (read — `Category { name, count }`)

**API**: `GET /api/categories` → `Category[]` — same endpoint, no change

**User's verbatim**: "jeg såg at kategori har du ikke gjort karousel eller speip effekt begge veier eller går runt?" + "det må ju være likt på knapper og di sveipe steder er samme"

**Decisions**:
- **3D cylinder carousel** med PanResponder drag (horizontal), `useNativeDriver: true` for 60fps
- **Animated.interpolate** per item: translateX, scale, opacity, rotateY basert på distanse fra activeIndex
- **Per-kategori neonfarger** fra webapp.py lines 786-828: Speed Limits=#FF6A00, Traffic Signs=#FFD700, Right of Way=#AAFF00, etc.
- **Active ring**: LinearGradient med Animated.loop rotasjon (React Native har ikke conic-gradient, simulerer med gradient + rotate)
- **"All Categories" som første item** i carouselen (matcher web), med cyan #00F5FF
- **PanResponder strategi**: `onStartShouldSet=false`, `onMoveShouldSet` kun ved horisontal drag > 10px. Pressable på items for tap (aktiv → start quiz, ikke-aktiv → snap til senter)
- **Swipe hint** auto-fade etter 5s delay (matcher web's `setTimeout 5000`)
- **Dots**: active=20px orange pill, adjacent=8px wider, rest=6px circle
- **Edge fades**: gradient Vignette left/right
- **TypeScript**: 0 feil
