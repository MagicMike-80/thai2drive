# 📊 Analyserapport: Teoritentamen.no vs Thai2Drive

---

## 🌐 HVA ER DETTE?

**Teoritentamen.no** er Norges største nettbaserte plattform for forberedelse til teoriprøven hos Statens vegvesen. Siden eies og drives av **Lime Green Digital AS**.

**Målgruppe:**
- Personer som skal ta førerkort i Norge (alle klasser)
- Både norsk- og engelskspråklige brukere
- Yrkessjåfører, ADR-sertifisering, utrykningssjåfører
- Trafikkskoler og lærere (B2B-segment via TGK-verktøy)

**Tilbyr:**
- Teoriprøver (øvingsoppgaver) for **alle** førerkortklasser i Norge
- Komplette digitale teorikurs med eBok, video og lyd
- Oppkjøringskurs
- Gavekort
- Trafikkskole-katalog
- Nyhetsartikler om førerkort/trafikk

**Sterkt salgsargument:** Anbefalt av Norges Trafikkskoleforbund (NTSF) og Trafikkforum – sosial bevis i toppklasse.

**Backend (gjettet):**

- Versjonerte assets (`1778230008` = cache-busting timestamp)
- Egen CDN: `cdn.teoritentamen.no`

**Analytics & Tracking:**
- Google Analytics 4 (`G-3VSF716RTX`)

**Annet:**
- Browserconfig for Microsoft tiles

**Vurdering:** Solid, men *konservativ* tech stack. Bygget for stabilitet, ikke "moderne hipness". Dette er en styrke – siden er rask og SEO-vennlig.

## 👥 BRUKERFLYT

1. **Discovery:** Bruker finner siden via Google (sterk SEO på "teoriprøve bil") eller anbefaling fra trafikkskole
2. **Landing:** Forsiden viser sosiale bevis (NTSF-anbefaling, 39k vurderinger)
3. **Klasse-valg:** Klikker på sin førerkortklasse (f.eks. "Personbil → Klasse B")
4. **Produktside:** Ser priser/tilgangsvarigheter (sannsynligvis 1 uke, 1 mnd, 3 mnd, 6 mnd)
5. **Kjøp:** Velger periode → betaling (kort/Vipps sannsynligvis)
6. **Onboarding:** Får tilgang, kan velge mellom:
   - Quick-quiz / øvingstest
   - Strukturert kurs gjennom eBoken
   - Video-leksjoner
7. **Læring:** Tar prøver, ser progresjon, repeterer svake områder
8. **Konvertering:** Består hos vegvesenet → forhåpentligvis anbefaler videre

**Gjettet manglende flow:** Adaptive læring / personalisert spaced repetition – fremgår ikke tydelig.

## 💰 FORRETNINGSMODELL

**Modell:** **Tidsbegrenset tilgangskjøp** (ikke abonnement, men "pass")

**Antatt prising (basert på markedet):**
- 1 uke: ~149 kr
- 1 måned: ~299 kr
- 3 måneder: ~399 kr
- 6 måneder: ~499 kr
- Premium/komplett kurs med eBok: 600–900 kr

**Inntektsstrømmer:**
1. Sluttbrukere (B2C) – hovedinntekt
2. **B2B til trafikkskoler** – TGK-lærerverktøy
3. Gavekort
4. **Affiliate/partnerskap:** Aprento for drosjeteori
5. Mulig: trafikkskole-listings (lead-gen)

**Styrker i modellen:**
- Naturlig "engangskunde" – men høyt prispunkt rettferdiggjør det
- Mange klasser = brede inntektskilder
- NTSF-anbefaling gir nesten monopol-aktig posisjon

2. **eBok-innhold** – pedagogisk skrevet

   - Quiz-motor med statistikk
   - Betalingsintegrasjon (Stripe/Vipps)

   - Admin-CMS for spørsmål
   - Analytics for læring

### Anbefalt teknologi (moderne stack):
- **Frontend:** Next.js 14 + TypeScript + Tailwind CSS + shadcn/ui
- **Backend:** Next.js API routes / tRPC, eller separat NestJS
- **Database:** PostgreSQL + Prisma
- **Auth:** Clerk eller NextAuth
- **Betaling:** Stripe + Vipps (norsk marked)
- **Video:** Mux eller Vimeo Pro
- **Hosting:** Vercel + Railway/Supabase
- **CMS for spørsmål:** Sanity eller egen admin
- **Analytics:** PostHog + GA4

### Kompleksitet: **KOMPLEKS** (men ikke umulig)

**Tidsestimat:**
- MVP (én klasse, basis quiz + betaling): **2–3 måneder**
- Konkurransedyktig produkt (3–4 klasser, video, eBok): **6–9 måneder**
- Full kopi (alle 15 klasser, B2B-verktøy): **18–24 måneder**

### Kritiske fokusområder:
1. **Innholdskvalitet** (60% av jobben) – ikke teknologi
2. **Pedagogisk design** – spaced repetition, adaptiv læring
3. **Mobile-first UX** – folk øver på buss/T-bane
4. **SEO** – kampen vinnes i Google på "teoriprøve bil"
5. **Sosial validering** – samarbeid med trafikkskoler tidlig
6. **Hurtighet** – sub-2s loading
